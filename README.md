# Spondon Dynamos Under 8 Bolts

![The Bolts U8 team](public/team/U8-match-3.jpeg)

The website for **Spondon Dynamos Under 8 Bolts**, a grassroots football team for under 8s, part of [Spondon Dynamos FC](https://spondondynamosfc.co.uk) and playing in the Derby Junior League.

The site has team news, fixtures, sponsors, contact details and the parent consent form.

🌐 **Website:** [WEBSITE_URL](WEBSITE_URL)

## Running locally

Built with [Next.js](https://nextjs.org).

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
